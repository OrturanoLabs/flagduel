# Catalogo e report generati

`catalog.json` e le SVG che contiene sono derivati dagli asset originali di `flag-icons` e `country-flag-icons`. Conservano gli avvisi e le condizioni MIT delle sorgenti: [flag-icons](../flags/LICENSE), [country-flag-icons](../flags-flat/LICENSE). Le fonti per ciascuna bandiera sono registrate in `report.json`.

Rigenerazione offline: `npm run preprocess`. Attribuzioni complete: [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).
